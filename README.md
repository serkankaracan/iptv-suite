# IPTV Suite

`IPTV Suite` henüz doğrulanmamış bir iç proje adıdır. **M1 — reproducible bootstrap**, **M2 — test altyapısı ve quality gates**, **M3 — domain terminology, validation ve safe errors**, **M4 — secure-storage foundation** ve **M5 — network/transport foundation** mühendislik kabulleri tamamlanmıştır. M5; expected-origin-bound HTTPS GET, bounded redirect/retry/timeout/decompression, cross-origin credential yasağı, typed safe failures, zeroing response/request buffer'ları, redacted operation observation ve `ConnectionProbeService` katmanını içerir. **M6 Xtream-compatible Live TV adapter** sıradaki milestone'dur; provider çağrısı, gerçek M3U parser, veritabanı, feature UI ve player henüz yoktur. Durable source lifecycle ve aynı SQLite transaction domain'indeki production katalog yerleşimi M8; production PFN update/reset/reinstall/repair, ikinci-user package registration/identity ve Store kabulü M15 kapsamında açık kalır.
